# RoboTwin Agent Web Console

该网页是现有终端 Agent 的第二个入口。它不会替换或复制机器人逻辑：

- Web服务启动时，后端预加载一个常驻RoboTwin场景和运动规划器。
- 网页刷新只重新读取状态，不会重复创建或关闭场景。
- 网页提交文字后，后端把任务发送给当前常驻场景执行。
- 指令被接受后输入框会清空，原始指令会显示在“执行记录”中。
- 仿真进程将正式头部、左腕、右腕三路画面发布给网页。
- 同一场景内每次任务的动作片段会依次合并到一个累计操作视频；重启
  Web服务创建新场景时才开始一份新视频。
- 终端命令仍可独立使用。

## 启动

只在服务器本机访问：

```bash
bash examples/my_parts_box_scene/run.sh --web
```

启动后网页会先显示“场景加载中”。看到“场景就绪”以及三路相机画面后，
即可发送任务。首次预加载期间不要重复启动另一个Web服务。

每次任务成功后，“Agent 指令”下方会显示“任务完成，还需要什么？”，
此时可以继续提交下一条指令。“下载操作视频”始终下载当前场景从第一条
指令到最近一条已结束指令的完整累计录像；网页刷新不会清空录像。

任务执行期间点击“停止任务”不会销毁或重新创建场景。当前动作会在最近的
安全中断点停止，夹爪张开，左右机械臂依次返回home状态；完成后同一场景
继续接收新的Agent指令。

先测试网页布局，不启动仿真器和大模型：

```bash
bash examples/my_parts_box_scene/run.sh --web --demo
```

局域网访问：

```bash
bash examples/my_parts_box_scene/run.sh --web --host 0.0.0.0 --port 8080
```

浏览器打开 `http://服务器IP:8080`。该服务未增加登录系统，只应在可信
局域网使用。更安全的远程访问方式是在本地电脑执行：

```bash
ssh -L 8080:127.0.0.1:8080 tiewenjie@192.168.9.208
```

然后打开 `http://127.0.0.1:8080`。

## 终端入口

原命令保持不变：

```bash
bash examples/my_parts_box_scene/run.sh \
  --agent-run "请帮我拿零件B"
```

同一时刻不要同时启动两个真实仿真任务，否则会争抢GPU显存和输出文件。
